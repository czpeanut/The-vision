# The Vision — 自習課學生讀書狀況辨識系統

利用教室監視器畫面，在自習課中每 30 秒自動辨識每位學生的狀態，並在發生危險行為時即時警示老師。

| 狀態 | 判斷依據 |
| --- | --- |
| 專心讀書 | 在座位上、低頭閱讀/書寫或坐姿端正，且動作平穩 |
| 玩手機 | 座位範圍內偵測到手機，且手機在學生手腕附近 |
| 趴睡 | 頭部低於肩膀，或看得到肩膀但臉埋在手臂中 |
| 分心 | 頭明顯轉向一側 (與鄰座聊天、東張西望) |
| 動作過大 | 連拍影像間身體/手臂大幅移動 (起身、揮手、打鬧) |
| 離開座位 | 座位上沒有偵測到人 |
| 無法判斷 | 有人但肩膀/臉被遮擋 |

全班層級的**警示**：

* ⚠️ 離座走動：走道上有人 (講台等「忽略區」除外)
* 🚨 疑似打鬧 / 肢體衝突：兩人距離很近且動作很大，或相鄰座位同時動作過大
* 🚨 疑似跌倒：座位外有人呈橫躺姿勢

危險警示會在看板上以紅色顯示並發出提示音，同一事件持續發生時不重複記錄 (預設 2 分鐘冷卻)。

## 運作方式

```
監視器 (RTSP) ──► 每 30 秒連拍 5 張 ──► YOLO 姿態 (17 關鍵點) + YOLO 物件 (手機/書)
                                                  │
           老師框好的座位 ──► 把每個人分配到座位 ──► 規則判斷 ──► SQLite ──► 看板 / 報表
```

* **為什麼連拍？** 單張照片看不出「打鬧」，連拍間的關鍵點位移可以估計動作幅度；姿勢判斷也用多數決，降低單張誤判。
* **門檻與距離無關**：所有距離都除以該學生的肩寬，前排、後排共用同一組門檻。
* 主要程式：`the_vision/classifier.py` (判斷規則)、`detector.py` (YOLO)、`monitor.py` (定時辨識)、`web/` (網頁介面)。

## 安裝

需要 Python 3.10 以上。有 NVIDIA GPU 時建議先依 [PyTorch 官網](https://pytorch.org) 安裝 CUDA 版 torch。

```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml   # 修改 camera.source 為教室監視器的 RTSP 網址
python -m the_vision.tools.fetch_models   # 下載模型 (只需一次)
python -m the_vision                 # 開啟 http://localhost:8000
```

## 完全離線運作

系統**不使用任何雲端 API**：影像辨識在本機執行，網頁介面也不載入外部資源，畫面不會離開學校。
預設為離線模式 (`detector.offline: true`)，會關閉 ultralytics 的連網檢查與使用統計回傳，也不會自動下載模型。

只有「準備安裝檔」這一步需要網路，可以在任何一台有網路的電腦上完成：

```bash
# 在有網路的電腦 (需與教室電腦相同作業系統與 Python 版本)
python -m the_vision.tools.fetch_models          # 下載模型到 models/ (約 25 MB)
pip download -r requirements.txt -d wheels      # 下載所有 Python 套件 (含 torch，約 1~3 GB)
```

把整個專案資料夾 (含 `models/` 與 `wheels/`) 用隨身碟複製到教室電腦後：

```bash
pip install --no-index --find-links wheels -r requirements.txt
python -m the_vision
```

之後教室電腦即可拔掉對外網路，只需要能連到監視器 (同一個區域網路) 即可。
這個流程已在完全沒有網路介面的環境中驗證過：模型載入、辨識、整堂課的監看與報表都能正常運作，且沒有任何連網嘗試。

## 使用流程

1. **框選座位** (`/setup`)：按「重新擷取畫面」取得目前監視器畫面，拖曳框出每位學生的上半身與桌面範圍，放開後輸入姓名。講台、門口等老師會走動的地方用「框忽略區」框起來。按「儲存座位」，下次上課可直接沿用 (座位調動時再修改即可)。
2. **開始監看** (`/`)：輸入課堂名稱 (可留空)，按「開始本堂監看」。看板每次辨識後更新畫面、每位學生的狀態與最近的狀態軌跡，右側列出警示。
3. **結束本堂課**：自動跳到報表頁，顯示每位學生的專注度 (專心讀書次數 / 可判斷次數)、狀態分布、時間軸與警示紀錄，可下載 CSV (Excel 可直接開啟)。

## 調整準確度

各教室鏡頭的高度與角度不同，**上線前請先用一段實際錄影校正門檻**：

```bash
python -m the_vision.tools.replay 錄影.mp4 --layout data/layout.json --debug
```

會依影片時間每 30 秒輸出一次結果，`--debug` 會列出每個人的「頭高」「轉頭」「動作」原始數值。對照畫面，把 `config.yaml` 的 `rules` 調到能區分各狀態即可。常見調整：

* 鏡頭很高、學生看書時頭壓得很低 → 調低 `sleep_head_height`
* 正常翻書也被判「動作過大」→ 調高 `active_motion`
* 手機偵測不到 → 提高 `detector.img_size`、改用 `yolo11m.pt`；最有效的方法是用自家教室畫面標註手機，微調一個專用模型後設定 `detector.object_model`

**已知限制**：手機藏在桌面下、被書本擋住時看不到；鏡頭只拍到背面的學生無法判斷轉頭；畫面中太小 (後排、廣角) 的學生關鍵點會不穩定，建議每間教室的畫面中學生上半身至少約 60 像素高。

## 測試

```bash
python -m pytest
```

測試使用合成的姿態資料驗證每一條判斷規則，以及網頁 API 的完整流程，不需要模型或攝影機。

## 隱私與使用規範

本系統處理的是可識別個人的影像與行為紀錄，屬於個人資料。實際使用前請：

* 依學校規定及《個人資料保護法》告知學生與家長蒐集目的、範圍與保存期限，並取得必要同意。
* 只讓授權的老師存取系統 (預設沒有登入機制，請只在校內網路使用，或架在需登入的內網後方)。
* `save_snapshots` 預設只保存有警示時的畫面；請定期清除 `data/` 下的舊資料。
* 辨識結果僅供老師參考，可能誤判，**請勿作為處分學生的唯一依據**。
